> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and measure, on the DFL benchmark only, a learned hold (P29), one-sided shape features (P30) and a
dead-ball-neutral decoder flag (P31), each against a bar declared beforehand, leaving `main.toml` and the submission
file untouched for Tian to decide in the morning.

**Architecture:** Every lane adds an opt-in parameter whose default is today's behaviour, a benchmark config that
turns it on, and one or two measurements. Code is written by subagents in a development worktree; every measurement
runs from the main checkout, detached at a commit, one heavy process at a time. A lane that misses its gate or bar is
reverted and logged.

**Tech Stack:** Python 3.11.9, numpy 2.4.6, pandas 3.0.6, scikit-learn as pinned in `requirements-benchmark.txt`; no
new dependency. Checks are `pipeline/selftest.py` and `pipeline/benchmark/selftest.py`.

**Spec:** `docs/superpowers/specs/2026-11-12-p29-p31-design.md` (the gates, picks and bar are declared there; read it
with this plan).
