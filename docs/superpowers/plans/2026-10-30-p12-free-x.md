# Part B, P12: the `free_x` refiner (R016)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** abstain (`X`) inside `H` and `A` runs where the decoder's posterior for the decoded label is below a
threshold. spellF1 stays exactly unchanged; only macroF1 can move. Adopt it only if R016's bar passes.

**Spec:** design section 5.B. The p < F1/2 argument and the expectation (likely small) are there.

**Branch / worktree:** `git worktree add ../BarcaHackathon-p12 -b p12-free-x main` (after Task 0).

## Task B.1: the refiner

**Files:**
- Create: `pipeline/refine/free_x.py`
- Modify: `pipeline/refine/__init__.py` (register `"free_x": free_x.refine`; mention it in the docstring)
- Modify: `pipeline/refine/README.md` (the "What is here now" table and the P12 candidates row)
- Test: `pipeline/selftest.py`

**Interfaces:**
- Consumes: `Decoded(labels, posterior)` (`pipeline/contracts.py`), where posterior is `(len(block), 3)`, columns
  P(H), P(A), P(D). `hmm` gives one with `posterior = true` in `[decoder]`.
- Produces: `refine(ctx, decoded, *, threshold, margin=3) -> Decoded`, which returns new labels and the same
  posterior object.
  - `threshold` is a float in [0, 1]; refuse bool, NaN and anything outside.
  - `margin` is an int ≥ 1; refuse bool.
  - A frame i becomes `X` iff:
    - its run (maximal stretch of one label in `decoded.labels`) is `H` or `A`;
    - `i − run_start ≥ margin` and `run_stop − 1 − i ≥ margin`;
    - `decoded.posterior[i, label] < threshold`.
  - With `decoded.posterior is None`, raise `ValueError("free_x needs the decoder's posterior: set posterior = true in
    [decoder], and put free_x before shift_edges, which drops it")`.
- `# Params`: `MARGIN = 3`, with the comment "frames: more than shift_edges' largest move in main.toml (2), so a
  shifted edge never reaches an X (design 5.B)".

- [ ] **Step 1: Write the failing tests** in `pipeline/selftest.py`:
  - `test_free_x_only_inside_possession_runs`: a hand-built labels and posterior. `X` appears exactly on the frames
    meeting the three conditions; `D` runs and frames within `margin` of a run's edges never become `X`, even with
    posterior 0 there.
  - `test_free_x_leaves_spell_f1_unchanged`: 200 random cases (`default_rng([0, 1612])`).
    - Each case has a random GT and decoded labels made of runs of H/A/D, a random posterior, and a random threshold.
    - `pm.evaluate(gt, refined)["spell_f1_mean"] == pm.evaluate(gt, decoded)["spell_f1_mean"]` exactly, on one valid
      graded block.
    - Follow how other selftest checks call `possession_metrics` on synthetic arrays.
  - `test_free_x_threshold_zero_is_identity`: `threshold=0.0` returns labels equal to the input.
  - `test_free_x_without_posterior_says_what_to_do`: `expect_error(ValueError, ..., "posterior = true",
    "before shift_edges")`.
  - `test_free_x_rejects_bad_parameters`: thresholds `-0.1, 1.1, nan, True, "0.5"`, and margins `0, -1, 1.5, True`.
  - `test_free_x_absent_leaves_configs_unchanged`: run `main.toml` and `smooth50_repro.toml` on the synthetic bundle;
    their outputs are unchanged by this branch (sha256 as before; reuse the existing synthetic run helper).
