> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement these plans task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** build the five parts of the design. Each part has its own branch, worktree and checks, and a scored part is
adopted only by a bar declared before its runs.

**Architecture:** every part plugs into the existing pipeline as a component in a stage registry (evidence or refine),
as a measurement tool under `pipeline/benchmark/`, or both. Nothing changes `pipeline/contracts.py`. Configs choose the
components. Heavy runs go through one sequential, throttled queue run by the controller.

**Tech stack:** Python 3.11.9; numpy 2.4.6 and pandas 3.0.6 (pipeline); scikit-learn only under `pipeline/benchmark/`
(as pinned); new: `imageio-ffmpeg` (P10, pinned). The repository has no test framework: checks are plain `test_*`
functions that `pipeline/selftest.py` and `pipeline/benchmark/selftest.py` discover by name.

## Global constraints (every task's requirements include these)

- **No match data to an LLM, including you.**
  - Never Read, cat, head or grep anything under `data/`.
  - Never print rows of tracking, tags, audio samples, homography, or per-frame outputs of a source on BAR-ATH.
  - Print and commit aggregates only: counts, shares, medians, quartiles, hashes, pass/fail.
  - `evaluation/gt/` and `evaluation/results/baseline_*.csv` are public and may be read.
- **Never commit** match data or per-frame derived data. Caches go under `data/cache/` (gitignored).
- **Don't modify `evaluation/`.**
- **The public window chooses nothing.** It may be scored only as a correctness check, and no constant, threshold,
  weight or adoption may come from it (RULES.md, `f8f2629`, T01, T27). No hand labels on this match.
- **Run everything with the main checkout's venv**, with the data directory pointed at the main checkout:

  ```bash
  export MTAH_DATA_DIR=C:/Users/Tian/Desktop/BarcaHackathon/data
  PY=C:/Users/Tian/Desktop/BarcaHackathon/.venv/Scripts/python
  $PY pipeline/selftest.py                 # synthetic, seconds: run after every change
  $PY pipeline/benchmark/selftest.py       # synthetic benchmark checks, seconds
  ```

- **Heavy runs are NOT yours to start.** Any step marked **HEAVY** goes to the controller, who runs it in the
  sequential, throttled queue. HEAVY means:
  - `pipeline/run.py` on the real match;
  - `selftest.py --data`, and `benchmark/selftest.py --dfl` or `--data`;
  - `benchmark/run.py`, `train_*.py`, `fidelity.py`, `conventions.py dfl|latency|public`;
  - the audio decode;
  - anything that loads BAR-ATH or DFL data.

  Write the exact command in your report and stop at that step.
- **Randomness** comes from `np.random.default_rng([seed, <a constant of the component's own>])` (T22).
- **Every new import in `pipeline/`** is pinned in `requirements-pipeline.txt` in the same commit.
- **Commits.** One per tested step. Messages are short and imperative, like the history (`git log --oneline -20`). No
  AI attribution and no `Claude-Session` trailer (managed policy). Push your branch to `origin` after committing
  (`git push -u origin <branch>`; check `git remote -v` first, `origin` must be `TianK003/BarcaHackathon`).
- **Style.** Match the surrounding code: module docstrings that argue the why, `# Params` blocks for constants,
  keyword-only parameters validated with a sentence that names the parameter, and plain `test_*` functions with
  `assert ... , "message"`. Comment density is like the neighbours'.
- **Docs.**
  - Results entries use the IDs reserved in the spec (A15, R016–R019).
  - A declaration (part 1) is committed before any run it governs, and is never edited after a run.
  - A new trap takes the next free `T` number.
  - Update `docs/proposals.md` (status, overview row) and the stage README tables when your part finishes.

## Review focus (across all parts)

1. **A source on a frame outside the graded blocks.** It must say NaN, never a vote. Each source task has a check.
2. **A config that names a match-only source, run on the benchmark without `--drop-match-only`.** It must give the old
   error plus a hint naming the flag, never a silent drop. Covered in Task 0.
3. **`free_x` after `shift_edges`, which has dropped the posterior.** It must raise a sentence saying to put `free_x`
   before `shift_edges`, never silently do nothing. Covered in P12 Task 1.
4. **A tag or whistle exactly at a block edge, or spanning halftime.** The votes must be cut at the block edges, half-open.
   Covered in P08 Task 1 and P10 Task 3.
5. **Reading a v1 shape model file after v2 exists.** `main.toml` must stay byte-identical until adoption. Covered in
   P09 Task 4.
